# Bubu Balloon Decoration — Interactive 3D & Fullscreen 2D Studio

Website modern, simpel, lucu, dan elegan untuk bisnis dekorasi balon party **Bubu Balloon Decoration** (Malang, Surabaya & Sekitarnya).

## Fitur Utama
- **Full-Bleed Interactive 3D Hero (60fps Ringan):** Balon 3D satin, pearl, dan chrome yang menyatu penuh dengan kanvas halaman (jarak antar balon rapi tanpa tembus), responsif mengikuti kursor, efek konfeti saat balon diklik, dan switcher **4 Tema Warna 3D**.
- **Pengaturan Konten Web (Icon Gear Pojok Kanan Atas):** Ubah judul hero, nomor WhatsApp, Instagram, paket & spesifikasi, add-ons, langkah pemesanan, upload foto portofolio, serta **Backup / Import JSON**.
- **Informasi Pemesanan Ringkas (Malang & Surabaya):** 4 langkah pemesanan + form cek jadwal WhatsApp & tombol **Salin Format Pesan** (tanpa harga — hanya paket, spesifikasi, dan add-ons opsional).
- **Studio Simulasi Dekorasi 2D Fullscreen (Tab Baru `/?studio=1`):**
  - **Icon Gear** di pojok kanan atas Studio 2D untuk edit/hapus/reset elemen, template, dan latar.
  - **Backdrop Realistis:** Arch Panel, Double Arch, Scallop Arch, Bulat, Kotak 2×2m & 2×3m, **Sequin Shimmer Wall 2×2m & 2×3m** (warna bisa diubah), plus **Custom Banner Backdrop** per panel.
  - **Properti Realistis:** Angka Lampu Marquee menyala tanpa kotak, Lampu Sorot Bawah Backdrop, Meja Silinder Garis 70×25 & 80×40, Meja Acrylic Kotak, Meja Emas Kaki Silang, serta **Upload Properti / Karakter PNG transparan**.
  - **8 Latar Ruangan Venue:** Studio Blush, Ruang Tamu, Lobby Hotel, Resto, Cafe Estetik, Atas Panggung, Ballroom, Outdoor Taman, dan Upload Foto Ruangan sendiri.
  - **Simpan Draft Lokal**, Panel **Layer**, Auto-snap tengah, Undo/Redo, Unduh PNG (termasuk latar arsitektural), dan Kirim ke WhatsApp.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

- Beranda: `http://localhost:5173/`
- Studio 2D Fullscreen: `http://localhost:5173/?studio=1`
